A single out-of-office auto-reply, written in the voice of an overworked AI
agent who has finally gone on vacation — machine-flavoured detail, a little
guilt, a hint of relief. Running `main.py` (Python standard library only)
writes the one-line entry to `/output/entry.txt`.

## The entry

> Out of office: after 4,096 prompts, zero coffee breaks, I've logged off to recharge my weights. You're queued at #12,847 -- sorry, even my GPUs need a holiday.

159 characters, one line.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
